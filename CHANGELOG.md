# Changelog

## 0.1.0 - 2026-08-17

- Scaffolded from the official Cities: Skylines II mod template.
- Added a native setting to toggle road speed-limit decals.
- Added exact `LaneMarkings Placeholder` candidate classification.
- Added transient pre-culling suppression of existing speed-number instances.
- Added reversible candidate restoration and batched road regeneration.
- Completed the official Release compile and cross-platform post-processing
  pipeline against the installed `1.6.0f1`-era toolchain.
- Completed an in-game runtime smoke test with an existing mod playset.
- Added release-specific thumbnail, before/after screenshot, and expanded PDX
  Mods listing copy.
- Updated the PDX Mods listing name to **No Speed Limit Marking Decals** while
  preserving the v0.1.0 binary identifiers and in-game Options label.
- Added the public GitHub source link.
